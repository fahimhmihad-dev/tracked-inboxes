# Tracked Inboxes — Sign-in Web App

A sign-in web app where an inbox (prefix@getyourservicebd.store) is auto-created for the user on signup.

🔗 **Live Website:** https://getyourservicebd.store

## About the Project
A small web application built around a simple idea: when a user signs up, a tracked inbox address on the getyourservicebd.store domain is automatically created for them.

## Features
- User sign-in / signup flow
- Automatic inbox address creation on signup
- Deployed on a custom domain

## Tech Stack

- HTML5, CSS3
- Built with AI-assisted development tools (Lovable / Antigravity workflow)
- Deployed live on a custom domain

## What I Learned

- Domain-based app concepts
